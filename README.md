# StudyMate — Student Planner

A clean, responsive student planner built with **HTML, CSS and JavaScript**. It helps students organise assignments and study tasks in one simple dashboard.

## Features
- Add tasks with a subject and due date
- Mark tasks as completed
- Filter tasks: All, Pending and Completed
- View total tasks, completed tasks and progress percentage
- Save a daily focus note
- Automatically saves data in the browser using `localStorage`
- Responsive layout for mobile, tablet and desktop

## Run locally
1. Download or clone this repository.
2. Open the `index.html` file in your browser.
3. Add your first study task.

No installation or build tools are required.

## GitHub setup
1. Create a new repository on GitHub named `student-planner`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish your site.
